# 墨页 MOYE

一款直接操作本地文件的轻量 Windows Markdown 编辑器。无账户、无仓库、无云同步。

## 1.1 更新：重命名、右键菜单与格式粘贴

- **重命名**：点击顶部文件名、按 F2，或在当前文件名上右键选择“重命名文件”。原文件在当前文件夹内改名；保留未保存的编辑及撤销记录；不覆盖同名文件。未保存的新文档可以先命名，再保存。
- **编辑区右键**：撤销、重做、剪切、复制、粘贴、粘贴为纯文本、删除选中文字、全选、查找替换、加粗、插入标题、整理 Markdown 格式，以及保存和另存为。
- **预览区右键**：复制选中文字、复制 Markdown 源码、全选及文件操作。
- **保留粘贴格式**：普通粘贴会把剪贴板 HTML 中的标题、加粗、列表、表格等转换成 Markdown；从源码复制的 Markdown 尽量保持原样。转换在本机完成。
- **原样粘贴**：Ctrl+Shift+V 或右键“粘贴为纯文本”。代码块内粘贴自动保持源码。
- **保留换行**：预览默认逐行显示原文，适合歌词、诗歌。点击预览顶部“保留换行”可切回标准 Markdown 的段落换行；只影响显示，不会修改文件内容。
- **标题层级**：右键可把当前行或选中的行设为一级或二级标题，工具栏 H₂ 也可设置二级标题。已经有标题标记时会替换层级。
- **修复已粘贴的内容**：选中文字后右键“整理 Markdown 格式”；无选区时处理全文。可整理全角井号、标题缺失空格、常见特殊空格、被转义的行首标题和包住整段内容的 `markdown` / `md` 代码围栏，代码块及元数据保持原样。可用 Ctrl+Z 撤销。
- 如果来源只提供已经丢失格式的纯文本，没有任何标题符号或 HTML，无法可靠推断原来的标题层级；此时可选中标题行点击工具栏 H₂。

从旧版升级时，先保存旧窗口的文字，再打开新版文件夹内的 `Moye.exe`。如果旧版还在运行，可以并存使用独立版本目录，避免覆盖运行中的程序文件。

## 开始使用

双击 `Moye.exe`，点击 **打开** 选择文件，或者将一个 Markdown 文件拖进窗口。编辑后按 **Ctrl+S** 保存到原位置，按 **Ctrl+Shift+S** 另存到你选择的位置。

请保留 `Moye.exe`、旁边的 DLL 和 `ui` 文件夹在一起。整个 `Moye` 文件夹可直接移动，不需要安装。

**不要只单独复制 EXE。** 新建文档保存前会询问存放位置；退出或切换文档时会提醒保存未完成的修改。没有自动保存，记得随手按 Ctrl+S。

系统需求：Windows 10 / 11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。程序复用已安装的运行环境，不捆绑完整浏览器。

## 文件与兼容性

- 支持打开 `.md`、`.markdown`、`.mdown`、`.mkd`、`.mkdn`、`.mdwn`、`.mdtext`、`.rmd`、`.qmd`、`.mdx` 及其他纯文本文件。打开对话框可选择“所有文件”。
- 通用 Markdown、GFM 表格、删除线、任务列表、脚注、内嵌 HTML 的安全子集和相对路径本地图片可预览。
- YAML front matter 完整保留在源码和保存文件中，预览不显示它。
- LaTeX、Mermaid、MDX、Obsidian 双链等专用语法保留为文本，不执行、不转换，当前不提供这些扩展的专门渲染。
- UTF-8（含 BOM）、带 BOM 的 UTF-16/32 自动识别；非 UTF-8 文本尝试按 GB18030（含 GBK）读取。无法读取时不会替换字符后强行打开。
- 如果旧文件乱码，可点击状态栏编码，用 UTF-8 / GB18030 / Windows-1252 重新打开。编码自动探测无法保证识别所有历史编码。
- 保存保留原编码、BOM、主要换行方式。未修改的文件另存时逐字节保留原内容；有修改的文件统一为原文件占比最高的换行方式。
- 使用同目录临时文件及原子替换保存。遇到只读、权限或磁盘错误会保留当前编辑内容并提示；可另存到其他位置。网络盘或不支持原子替换的文件系统可能无法覆盖保存。
- 保存时检测磁盘内容变化，避免无提示地覆盖其他程序的修改。
- 单个文件上限 64 MB；超过 200 万字符暂停实时预览，仍可编辑和保存。它适合日常文本，不是大型日志编辑器。

## 本地与离线

所有界面资源均随程序附带。文件预览不请求远程图片、字体、脚本或网页；点击外部链接只显示离线提示。相对图片路径只能读取当前文档文件夹及其子文件夹，`../` 或绝对路径图片不会加载。程序无遥测、账户、更新检查或联网业务功能。

WebView2 是系统组件，其自身更新策略由 Windows / Edge 管理。运行环境本身不随本程序分发。

最近文件路径记录位于 `%LOCALAPPDATA%\Moye\recent.json`；主题和视图设置保存在该目录的 WebView2 配置中。程序不会将文档复制进资料库。默认不提供崩溃恢复，因此未保存文字可能在进程异常退出时丢失。

## 设置为 Markdown 默认打开器（可选）

在资源管理器中右键任意 `.md` 文件 → **打开方式** → **选择其他应用** → 选择 `Moye.exe`，按 Windows 的提示设置默认值。墨页不会自行修改文件关联。程序接受命令行文件参数，因此双击关联文件会直接打开该文件。

## 从源码构建

构建阶段需要网络下载依赖；构建完成后使用无需网络。

```powershell
npm.cmd ci --cache .build/npm-cache
npm.cmd test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-native.ps1
npm.cmd run package
```

产物在 `release/Moye/`，原生外壳使用系统自带的 .NET Framework C# 编译器，无需 Visual Studio。前端使用 CodeMirror 6、markdown-it、DOMPurify 和 Lucide；许可见 `THIRD-PARTY-NOTICES.txt`。
