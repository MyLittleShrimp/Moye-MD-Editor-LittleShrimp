# 42 秒宣传片原始分镜

此文档记录脚本生成的初版分镜。当前发布视频使用作者提供的约 40 秒剪辑，精确时长与文件校验值见 `video-info.json`。

视觉：暖白与灰绿；纸张般的轻柔底色；真实界面卡片、阴影、平移与淡入淡出；后半段转入深色。

| 时间 | 主文案 | 画面 |
| --- | --- | --- |
| 00–05s | 留一点空间，给文字。 | 品牌、编辑器主界面、Windows x64 / 无需账户 |
| 05–12s | 文件在哪，就在哪写。 | 欢迎页切到双栏编辑；打开、编辑、保存、另存为 |
| 12–19s | 左边落笔，右边成文。 | 双栏切换到预览；大纲、任务清单、表格 |
| 19–26s | 常用操作，一次右键。 | 编辑区菜单切换到重命名弹窗 |
| 26–32s | 复制过来，格式也留下。 | 空白文档切换到真实富文本粘贴结果 |
| 32–38s | 换个主题，继续专注。 | 深色双栏切换到深色专注预览 |
| 38–42s | 让想法，留在你的文件里。 | 品牌收尾：本地文件 / 离线使用 / 专注书写 |

配乐：稀疏的电钢琴式音色与柔和持续和弦，片头淡入、片尾淡出。无旁白，关键文案已显示在画面中。

真实功能说明：普通粘贴只能保留剪贴板仍包含的文字 / HTML 语义格式，无法还原来源已经丢失的标题层级；视频在该镜头保留了来源条件提示。
