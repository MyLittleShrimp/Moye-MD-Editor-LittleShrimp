# 慢一点，把想法写下来

让注意力回到文字本身。

这是一份普通的 **Markdown 文件**。它不属于某个仓库，也不需要一个账户；你可以把它放在桌面、工作文件夹，或任何喜欢的位置。

> 不必等到想清楚才开始写。
> 有时候，书写本身就是想清楚的过程。

## 今天，想做的三件小事

- [x] 给脑海里的想法找一个落脚点
- [ ] 写下一个值得记住的瞬间
- [ ] 留一点空白给明天

## 简单，也足够好用

用 `Ctrl + S` 保存，用 `Ctrl + Shift + S` 另存一份。

| 你想做的事 | 在墨页里 |
| --- | --- |
| 心无旁骛地写作 | 切换到编辑视图 |
| 边写边看效果 | 使用双栏视图 |
| 从头读一遍 | 打开预览或专注模式 |

## 给未来的自己

文字不一定要完美。先把它写下来，然后慢慢修改。

**保持好奇，认真生活。**
